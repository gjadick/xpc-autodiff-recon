Author: Andrew Ferretti
Description: Multislice and projection approximation iterative reconstructions
of XPC-CT data. The folder tuned_recons has .py files for generating and
reconstructing data with the multislice and projection approximations. The
folder image analysis has some code for analyzing the resulting images and
making some figures.
